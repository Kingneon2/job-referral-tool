# Job Referral Web Tool

A simple, responsive full-stack web application built for managing job employee referrals. Developed as part of the Mercor technical assessment.

## Tech Stack
* **Frontend:** Plain HTML5, CSS3, and JavaScript (Vanilla JS via Fetch API)
* **Backend:** Python (Flask) with CORS support
* **Storage:** In-memory Python list (temporary storage)
* **Version Control:** Git & GitHub

## Features
* **Submission Form:** Submit new candidate referrals with validation (referrer name, candidate name, email, job title, and reason).
* **Referral Dashboard:** View all submitted referrals in a clean, responsive data table.
* **Analytics Widget:** Real-time counter showing total submissions and the number of unique job titles.
* **Deletion:** Remove specific referrals dynamically from the system.
